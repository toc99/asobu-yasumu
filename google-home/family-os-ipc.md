# Optional Family OS IPC (development)
Linux only, opt in with GH_FAMILY_OS_IPC=1 in the existing local env file. Same user and existing lifetime-flock-protected bridge. No TCP or Firebase rule changes. Socket .local/family-os.sock in a private directory. Existing bridge is the sole Cast executor. Family OS waits for idle, obeys both quiet policies, selects discovered devices by UUID. No retry after ambiguous playback. This is a development branch, not a release or deployed change. Test with node --test tests/family-os-ipc.test.mjs; verify actual device playback before production. Disable opt-in and restart bridge to roll back.
