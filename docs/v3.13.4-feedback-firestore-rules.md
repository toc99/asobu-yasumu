# あそぶ・やすむ v3.13.4 — 子どもの意見箱 Firestore Rules 追加パッチ

**このファイルは本番Rulesの全体ではありません。** 現在公開中のFirestore RulesをFirebase Consoleからバックアップし、以下の `match` ブロックだけを**既存の** `match /households/{h}` の内側に追加してください。
既存のv3.13.3のルールは削除・上書きしないでください。

`isMember(h)`、`isKid(h)`、`isParent(h)` は現行Rulesで利用されている既存の権限判定関数を前提とします。

```javascript
match /feedbackReports/{reportId} {
  // iPadアカウントは共有のため、同じ家族の子ども同士のデータ分離は
  // UI上のフィルタのみ。Firestore上では家族アカウントで参照可能。
  allow read: if isMember(h);

  allow create: if isKid(h)
    && request.resource.data.keys().hasAll([
      'childId','type','title','description','status',
      'createdBy','createdAt','parentReply','reviewedBy','reviewedAt'
    ])
    && request.resource.data.keys().hasOnly([
      'childId','type','title','description','status',
      'createdBy','createdAt','parentReply','reviewedBy','reviewedAt'
    ])
    && request.resource.data.childId in ['older','younger']
    && request.resource.data.type in ['feature','bug']
    && request.resource.data.title is string
    && request.resource.data.title.size() >= 2
    && request.resource.data.title.size() <= 60
    && request.resource.data.description is string
    && request.resource.data.description.size() >= 2
    && request.resource.data.description.size() <= 1000
    && request.resource.data.status == 'new'
    && request.resource.data.createdBy == request.auth.uid
    && request.resource.data.createdAt == request.time
    && request.resource.data.parentReply == ''
    && request.resource.data.reviewedBy == ''
    && request.resource.data.reviewedAt == null;

  allow update: if isParent(h)
    && request.resource.data.diff(resource.data).affectedKeys().hasOnly([
      'status','parentReply','reviewedBy','reviewedAt'
    ])
    && request.resource.data.status in ['new','reviewing','planned','done','declined']
    && request.resource.data.parentReply is string
    && request.resource.data.parentReply.size() <= 300
    && request.resource.data.reviewedBy == request.auth.uid
    && request.resource.data.reviewedAt == request.time;

  allow delete: if false;
}
```

## 本番公開手順
1. 現行Firestore Rulesと必要なデータをバックアップする
2. 上記ブロックを既存の `/households/{h}` 内へ追加しRulesを公開する
3. Firebase Emulator等でアクセス権と入力検証をテストする
4. GitHubの `feature/v3.13.4-kids-feedback` ブランチを `main` にマージする
5. GitHub Pages公開後に、iPadから報告し、保護者が対応・返事を登録できることを確認する

## 受入テスト（正負）
- 子ども：機能要望とバグ報告をそれぞれ送れる
- 子ども：タイトル1文字/空欄、長すぎる説明、想定外のstatus指定は拒否される
- 子ども：報告内容・状態を改ざんする更新や削除はできない
- 保護者：報告一覧を閲覧し、状態と300文字以内の返事を変更できる
- 保護者：childId、本文、createdBy、createdAtを変更できず、削除もできない
- 未認証・家族外アカウント：読み取り/作成/更新/削除ができない
- v3.13.3のゲーム時間・休憩・ポケモン獲得・チャレンジ承認に影響しない

注：送信アカウントは家族共用のkidユーザーです。子どもの個人別認証や別家庭との共有を行う設計ではありません。
