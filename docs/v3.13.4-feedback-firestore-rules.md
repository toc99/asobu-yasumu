# v3.13.4 Firestore Rules — 全文置き換え手順

v3.13.4からは、Firestore Rulesを「断片の追加」ではなく**完全版の全文置き換え**で公開する。

## 正式なRules全文
- [firestore.rules](../firestore.rules)（リポジトリ直下）
- [Raw（全選択・コピー用）](https://raw.githubusercontent.com/toc99/asobu-yasumu/feature/v3.13.4-kids-feedback/firestore.rules)

この `firestore.rules` は以前配布した **v3.13.3完全版**をベースに、`match /households/{h}` の内側へ
`match /feedbackReports/{reportId}` を追加したもの。
既存のゲーム・休憩・チャレンジ・ポケモン報酬に関するルール本文は変更しない。

**注意**：現行Firebase ConsoleのRulesを直接取得して比較したものではない。
もし前回のv3.13.3公開後にFirebase側でRulesを個別修正している場合、その変更は含まれない。

## 全文置き換えの作業手順
1. Firebase Console → Firestore Database → **ルール（Rules）** を開く。
2. **今のRules全文をテキストに保存**し、バックアップする。
3. リポジトリの `firestore.rules` をRaw表示し、**最初の `rules_version = '2';` から最後の `}` まで全文コピー**する。
4. Firebase ConsoleのRules編集欄で全選択し、そのまま全文を貼り付ける。
5. 「公開（Publish）」する。エラーがあれば公開を中断し、バックアップに戻す。
6. 公開後、子ども・保護者のアカウントから新規報告・一覧・対応状況更新を確認する。
7. Rulesの適用を確認してからv3.13.4のGitHub PRをmainへマージする。

## 追加した権限
- 家族メンバー：報告の読み取り
- 子どもアカウント：`feature` / `bug` の新規投稿（題名2〜60文字、詳細2〜1000文字）
- 保護者アカウント：報告の対応状況5種類と返事（最大300文字）を更新
- 全アカウント：報告の削除は禁止
- 子ども：送信後の本文・対応状況の変更は禁止

## 動作確認
- 子どもの「いけんばこ」から要望とバグ報告を投稿できる。
- 保護者「承認・対応」から新着報告を読み、状態と返事を更新できる。
- 子ども画面で返事と対応状況を確認できる。
- ルールで未認証・家族外の読み書きを拒否する。
- 既存のゲーム時間・休憩・ポケモン・チャレンジが従来どおり動作する。

実機およびFirestore Emulatorでの統合試験は未実施。
